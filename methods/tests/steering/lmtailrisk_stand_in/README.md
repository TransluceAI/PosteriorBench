A stand-in for the checkout of rangell/LMTailRisk that `steering find-refusal-direction` and `steering build-vectors` import from. It has the files and the interfaces that `posteriorbench_methods/steering/refusal.py` and `coherence.py` name, with short code of our own in them, so the tests run without the checkout. The fixture `lmtailrisk_checkout` copies it and adds the instruction files of `refusal_direction/dataset/splits/`.
